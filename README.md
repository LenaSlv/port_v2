# Портфолио Елены Сулоевой

Статический сайт на HTML, CSS и JavaScript без сторонних зависимостей. Корневой `index.html` открывает актуальный транспортный кейс; отдельная главная страница портфолио пока не реализована.

```text
index.html                 входная страница сайта
src/
  assets/                  все ресурсы, используемые сайтом
  styles/                  стили страниц и прототипов
  scripts/                 поведение страниц и прототипов
  pages/                   дополнительные страницы кейсов
  prototypes/              сценарии внутри мокапов телефонов
  demos/orbita/            самостоятельное демо интерфейса мониторинга
docs/                      ТЗ, процесс работы, Figma и правки сайта
```

В корне из файлов самого сайта находится только `index.html`. `README.md`, `AGENTS.md`, `package.json`, `.gitignore` и скрытые служебные каталоги относятся к сопровождению репозитория.

## Использование

Сайт работает напрямую из `index.html` и `src/`; отдельная сборка и установка пакетов не нужны. Публикуемый набор файлов — `index.html` и `src/`. Документация и архивы не относятся к файлам сайта.

Для ручного локального просмотра можно запустить из корня `python -m http.server 8000`, если Python установлен. Нужен HTTP: при `file://` браузер может блокировать маски изображений. Основной кейс: `/index.html`; мониторинг: `/src/pages/monitoring.html`; демо: `/src/demos/orbita/`.

Старые релизы и прежние инструкции сохранены в [docs/archive](docs/archive/README.md). Единственный источник актуального сайта — `index.html` и `src/`.

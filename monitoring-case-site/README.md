# Мониторинг бортовых систем — кейс 02

Страница второго кейса портфолио Елены Сулоевой.

Источник: https://www.figma.com/design/ZGvSZcFNYGG8ePhMb3iuk0/?node-id=2883-26896

Статическая страница находится в `dist/index.html`; стили — `dist/style.css`, взаимодействия — `dist/index.js`. Экспорты интерфейсов сохранены локально в `dist/assets/`.

Для локального просмотра из этой папки: `python -m http.server 8001 --directory dist`.

Обложка использует реальный экран обзора вместо заглушки ноутбука. Повторяющийся блок администрирования показан один раз. Изображение в нём соответствует исходному фрейму: в Figma там пока установлен экран обзора, а не список пользователей.

Проверка адаптивности, изображений, увеличения экранов и мобильного меню: `node .local/check-monitoring.cjs` из корня портфолио.

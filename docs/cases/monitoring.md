# Мониторинг бортовых систем — «Орбита»

Страница: `monitoring-case/index.html`. Фрейм: [2883:26896](https://www.figma.com/design/ZGvSZcFNYGG8ePhMb3iuk0/?node-id=2883-26896).

Стили: `monitoring-case/monitoring.css`, `monitoring-case/results-animation.css`. Поведение: `monitoring-case/monitoring.js`, `monitoring-case/results-animation.js`. Ресурсы: `monitoring-case/assets/`.

Обложка использует реальный экран обзора внутри макета ноутбука. Повторяющийся блок администрирования показан один раз. В блоке администрирования используется экран обзора: согласно прежнему описанию кейса, такой экран находился в исходном фрейме. Это ограничение материалов; не подменять его выдуманным экраном пользователей.

Анимация результатов создаёт HTML-слои поверх изображения: фильтры, календарь, таблицу и диалог удаления. Время сценария идёт только при видимом блоке и активной вкладке. Её особенности описаны в `docs/site-adjustments.md`.

Известные отличия от требований общего портфолио: хедер пока не закреплён, вместо общей карусели есть одна ссылка на транспортный кейс, контактная кнопка ведёт к футеру. Эти задачи не реализуются автоматически при переносе файлов.


Прежний README ссылался на `.local/check-monitoring.cjs`, которого нет в Git. При переносе обновлены пути к странице, стилям, скриптам и ресурсам; визуальная проверка в рамках реорганизации не выполнялась.

# Портфолио Елены Сулоевой

Статический сайт на HTML, CSS и JavaScript без сторонних зависимостей. Главная страница портфолио — `index.html`.

```text
index.html                 главная портфолио
transport-case/            кейс единого транспорта
corporate-transport/       кейс корпоративного транспорта
monitoring-case/           кейс мониторинга
soul-case/                 кейс Soul
cashier-case/              кейс АРМ кассира
src/
  assets/                  ресурсы транспортного кейса и портфолио
  styles/                  стили страниц и прототипов
  scripts/                 поведение страниц и прототипов
  prototypes/              сценарии внутри мокапов телефонов
docs/                      ТЗ, процесс работы, Figma и правки сайта
```

Страницы кейсов находятся в отдельных папках в корне проекта; единый транспорт также использует файлы из `src/`.

## Использование

Сайт работает напрямую из `index.html`, папок кейсов и `src/`; отдельная сборка и установка пакетов не нужны. Документация и архивы не относятся к файлам сайта. Главная связывает пять локальных проектов. Общее контактное окно подключено на главной и страницах кейсов.

Для ручного локального просмотра можно запустить из корня `python -m http.server 8000`, если Python установлен. Нужен HTTP: при `file://` браузер может блокировать маски изображений. Единый транспорт: `/transport-case/`; корпоративный транспорт: `/corporate-transport/`; мониторинг: `/monitoring-case/`.

Старые релизы и прежние инструкции сохранены в [docs/archive](docs/archive/README.md).

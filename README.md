- [Опубликованный кейс](https://transport-design-case-2026.inni-re.chatgpt.site)

Страница находится в `index.html`. Для локального просмотра запустите в папке проекта `python -m http.server 8000` и откройте `http://localhost:8000/`.

Стили находятся в `style.css` и `hover.css`, логика крупного просмотра — в `index.js`. Обычные изображения экранов лежат в `assets/`, экспорты Figma в разрешении 3× для крупного просмотра — в `assets/zoom/`. Прозрачный контур телефона берётся из обычного изображения как маска. При открытии файла напрямую через `file://` браузер может блокировать маску, поэтому локально нужен HTTP-сервер.

Отступы по макету находятся в `style.css`. `layout.css` отвечает за закреплённый хедер и кнопку возврата наверх.

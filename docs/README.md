# Документация проекта

| Документ / папка | Назначение |
| --- | --- |
| [requirements.md](requirements.md) | ТЗ, состав сайта, требования и текущее состояние реализации. |
| [figma-frames.md](figma-frames.md) | Единый список ссылок на файл и утверждённые фреймы Figma. |
| [workflow.md](workflow.md) | Порядок изменения Figma, обновления сайта и сохранения правок реализации. |
| [site-adjustments.md](site-adjustments.md) | Реестр решений, которые необходимо воспроизводить в коде сверх статичного макета. |
| [design-guidelines.md](design-guidelines.md) | Подробные правила оформления и подачи кейсов; перенесены из актуального навыка с обновлением путей. |
| [cases/monitoring.md](cases/monitoring.md) | Особенности кейса мониторинга и известные ограничения материалов. |
| `references/figma/` | Локальные экспорты референсов и скриншоты прежних проверок на 1440 и 390 px. Не подтверждают состояние новой версии автоматически. |
| [archive/](archive/README.md) | Исторические релизы, прежняя копия навыка и настройки отдельного хостинга. |

Дизайн меняется в Figma. Техническое поведение и адаптация, которые нельзя полностью задать статичным фреймом, хранятся в `site-adjustments.md`. Документы различают реализованное и запланированное: наличие требования не означает, что оно уже работает на всех страницах.
